# AI Bootcamp

This repository documents my journey of learning Artificial Intelligence and Deep Learning from the ground up.

The goal is to understand the concepts instead of only using libraries. For every topic, I plan to study the theory, implement it from scratch whenever possible, and build small projects before moving on to larger AI applications.

As I progress, this repository will grow from Deep Learning fundamentals to modern topics such as Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and AI Agents.

## Repository Structure


More modules will be added as I continue learning.

## Learning Approach

For each topic, I follow a simple workflow:

* Learn the concept
* Write notes in my own words
* Complete coding assignments
* Build a small project
* Push the work to GitHub

The objective is not just to finish courses, but to understand how things work and become comfortable building AI systems from scratch.
